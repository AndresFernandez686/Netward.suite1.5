# Pop-up de producto ya cargado

Empleado B intenta cargar un producto cuya versión vigente pertenece a Empleado A. El guardado se detiene y devuelve el propietario, cantidad y versión actuales.

La interfaz muestra: `Este producto ya fue cargado por Empleado A. ¿Desea sobreescribir?`

Resultado: **Aprobado**.
