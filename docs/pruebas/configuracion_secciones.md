# Separación de Productos y Tiendas

**Objetivo:** cada opción del menú debe mostrar únicamente su módulo correspondiente.

- `Catálogo → Productos` muestra catálogo, alta y eliminación de productos; no renderiza tiendas.
- `Sistema → Tiendas` muestra sucursales y creación de tiendas; no renderiza productos.

Automatización: `tests/test_configuracion_secciones.py`.
